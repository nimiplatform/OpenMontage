# Nimi image explainer: assets

Use the App's Nimi scenario-job adapters for the configured image and speech capabilities. Require a currently available voice where the model offers presets. Present the selected models before approval and check the approved AIConfig revision immediately before each new submission.

Persist job references and uncertain submissions. Query retained unfinished jobs; never infer completion from a submitted request or blindly resubmit an uncertain request. Adopt actual artifacts through Nimi storage. Preserve unchanged media on revision, and record only returned provenance and media facts in the existing `asset_manifest` schema. When all media are available, save `awaiting_human` and present their previews. The material approval button completes this gate.
