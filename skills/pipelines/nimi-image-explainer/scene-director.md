# Nimi image explainer: scene plan

Use the supplied facts, target duration and any requested scene count to prepare editable scenes. The media worker supports 1–12 scenes; three is an acceptance sample, not a fixed product count. Each scene needs a title, plain narration and a concrete image description. Do not invent research, citations or a quote for model costs. Keep the text language and distinguish illustrative symbols from literal depictions.

The App's typed Nimi text client performs generation. Convert the accepted output into the existing `scene_plan` artifact; its initial timestamps are planning estimates. Save the stage as `awaiting_human`. Only the App's explicit plan confirmation completes this gate. Editing the plan invalidates downstream checkpoints and affected assets.
