# OpenMontage for Nimi 0.1.0

Initial Windows image-explainer integration. It uses the Nimi platform account, App Access, AI configuration and AI execution while OpenMontage retains ownership of production and approvals.

- Prepare an editable three-scene storyboard from supplied facts.
- Generate images and narration through configured Nimi capabilities, with an explicit voice choice.
- Confirm the plan and materials through schema-validated pipeline checkpoints.
- Preserve projects, job references and generated media in Nimi storage; retain completed media when retrying.
- Render 720p video locally, preview it and export MP4.
- Package Python, Node, Remotion, Chrome Headless Shell and media binaries through the official app-tools build.

The initial scope is supplied-material image explainers. Video-generation pipelines, music, transcription, avatars and other upstream OpenMontage workflows are not exposed by this version. This candidate's final Catalog installation and update acceptance is still pending; it is not yet a completed public release.
